  高频能量漏出。改 9×9 密集采样:间距 σ/2、覆盖 ±2σ、权重
  exp(-(k/2)²/2) 归一——有效核为平滑钟形,即 Web 引擎的柔和模糊;
  焦点行/无模糊 UI 仍走单采样快速路径

  hovered 永久卡死。改逐帧轮询 window.is_window_hovered()(平台
  WM_MOUSELEAVE 维护的事实源),丢事件也能在下一帧自愈
