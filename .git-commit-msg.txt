fix(gpui): 滚动并入绘制期变换——布局完全静态,新增像素级追踪

用户反馈:①稳定光栅方案不正统且出现"字间白色细线还会闪";②动画尾部
微动依旧;③希望有像素级追踪日志。

一、回滚"稳定光栅"补丁(根因正确性):
固定相位 + 分数位置采样的方案在图集瓦片边缘混入相邻字形像素,
即用户看到的字间白色细线(分数偏移变化时闪烁)。该补丁已整体回滚。

二、正统架构:滚动偏移也走 GPU 变换:
上游 AMLL 的滚动与缩放全部是 CSS transform(translateY + scale),
排版零重排。对齐之:所有歌词行恒定叠放在布局原点,posY 与缩放
全部经 with_element_transformation 的合成矩阵(p' = s·(p−C)+C+T)
在绘制期应用。字形绘制位置逐帧不变 → 上游默认光栅化天然稳定,
无逐帧重光栅、无分数采样,微动与白线两个问题从机制上同时消失。
行本体不再承载事件,改为全窗口点击映射层(按可视纵带命中 seek)。

三、像素级追踪(--trace-pixels <dir>):
- patches/gpui-pre-windows:DirectXRenderer::capture_last_frame
  (staging 纹理读回最近呈现帧,不重绘不影响呈现)
- patches/gpui-pre:PlatformWindow::capture_frame_pixels(默认 None)
  + Window 公开包装
- gpui-player:逐帧读回并做帧间逐像素差分,指标(meanDiff/
  changedPx/maxDiff)写入 trace JSONL,ev:"pixel";变化帧按 1/8
  采样存 PNG 供肉眼复核

像素数据结论(本轮采集,3356 帧):
- 所有过渡:平滑上升 → 单调衰减 → 到达后精确归零,稳态零残留
- 换行 8400 全程:峰值 2.66 → 1.6s 内单调衰减至 0.000,其后全零
- 大尖峰仅出现在剧本 seek 落点(行重新布局的 slow 滑入,符合预期)
- 无任何"稳态下的周期性像素变化"(此前微动的特征已不存在)

回归:23 测试全绿、clippy 0 警告、与上游对比指标不变
(scrollTo 0.07%、稳态 0.00px、缩放 ≤0.14%)。
